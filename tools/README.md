# tools/

Scripts that stand up, fill, probe and test against the **disposable** Trilium mock, and that screenshot the 3D view.
Run everything from the project root (several scripts read `.bootstrap.env` or `.playwright-*` relative to the current directory). Background: [wiki/Testing.md](../wiki/Testing.md), [wiki/Mock-and-Seeding.md](../wiki/Mock-and-Seeding.md), and `AGENTS.md` ("Trilium mock", "Verified ETAPI contract").

**Golden rule: no script here may be pointed at a real Trilium.** Most of them create and delete notes. `.bootstrap.env` (written by `trilium-bootstrap.sh`, gitignored, mode 600) holds the mock's URL and ETAPI token; do not print or commit it.

## Library files (not run directly)

| File | Role |
|---|---|
| `lib/vault-gen.mjs` | The deterministic vault generator: `PROFILES`, `generateVault(profile, {seed})`, `vaultStats`, PNG/PDF builders. No `Math.random`, no dates |
| `lib/vault-apply.mjs` | Writes a generated vault through ETAPI into any compatible server (`applyVault`, `pool`, `wireType`). It contains **no** safety checks: callers decide which server may be written to |

## Which tool when

| I want to ... | Use |
|---|---|
| Check my change without touching Docker | `npx tsc -b && node tools/unit-test.mjs && npm run test:mock` |
| Try the app without Docker | `npm run mock:fake -- --seed medium`, then `npm run dev` |
| Big vaults for the walk caps | `node tools/seed-vault.js large` (or `huge`, `deepchain`, `widefan`, `longtail`) |
| A fresh Trilium | `tools/trilium-bootstrap.sh --recreate` |
| See the 3D view without a browser window | `node tools/tree-shots.js looks` with the dev server running |
| The full gate before declaring something done | `npm test` (wipes the mock!) |
